Ligação ao Supabase

Gere fichas, perguntas, temas e relatos de problemas diretamente na base de dados.

Supabase → Project Settings → API Keys → Legacy API keys → service_role. As chaves novas sb_secret_… são bloqueadas pelo Supabase em navegadores. A chave fica só em memória: não é gravada e desaparece ao fechar ou recarregar o separador. Nunca a coloques no código nem a partilhes.

Temas

Temas usados por fichas podem ser renomeados, mas não mudam de disciplina/ano nem podem ser apagados (as versões publicadas dependem deles). Retirar um tema de uma ficha publicada cria uma nova versão; as versões antigas continuam ligadas ao tema e aparecem como «em versões antigas». Esses temas podem ser arquivados: deixam de aparecer no editor e aos responsáveis.

Relatos de problemas

Problemas reportados pelos responsáveis numa pergunta durante a revisão. Corrige a pergunta na ficha (cria uma nova versão) e marca o relato como resolvido.

Documentos legais

Termos de Utilização e Política de Privacidade. Cada publicação cria uma versão nova e imutável; os responsáveis aceitam versões concretas e o aceite fica registado (data, origem, IP). Alterações relevantes devem exigir novo aceite: os responsáveis veem o resumo das alterações no próximo acesso e não continuam sem aceitar. Use «Sem novo aceite» apenas para correções que não mudam direitos nem tratamentos (gralhas, contactos).
