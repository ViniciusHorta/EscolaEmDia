Ligação ao Supabase

Gere fichas, perguntas, temas e relatos de problemas diretamente na base de dados.

Supabase → Project Settings → API Keys → Legacy API keys → service_role. As chaves novas sb_secret_… são bloqueadas pelo Supabase em navegadores. A chave fica só em memória: não é gravada e desaparece ao fechar ou recarregar o separador. Nunca a coloques no código nem a partilhes.

Temas

Temas usados por fichas podem ser renomeados, mas não mudam de disciplina/ano nem podem ser apagados (as versões publicadas dependem deles). Retirar um tema de uma ficha publicada cria uma nova versão; as versões antigas continuam ligadas ao tema e aparecem como «em versões antigas». Esses temas podem ser arquivados: deixam de aparecer no editor e aos pais.
